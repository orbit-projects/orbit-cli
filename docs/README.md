# Orbit CLI documentation

Orbit CLI provides a local interactive operator interface over Core and explicitly composed
plugins. It does not act as an unauthenticated remote administration plane.

- [Interactive control room](cli/README.md)
- [Architecture and package boundaries](architecture/overview.md)
- [Development and verification](development/README.md)
- [Operations and security](operations/README.md)
- [Security model](security/overview.md)

The package is currently `0.1.0-alpha`. Its APIs and interaction design may change before a
stable release.
